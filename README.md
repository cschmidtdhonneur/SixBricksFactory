# Six Bricks Factory

Application francophone gratuite de génération d'activités Six Bricks.

Six Bricks Factory propose des idées d'activités à l'infini, avec ou sans plateau, pour stimuler le langage, les mathématiques, la mémoire, l'attention, la motricité, la créativité, les fonctions exécutives, les compétences sociales et le plaisir d'apprendre, de la petite enfance jusqu'au grand âge.

## Fonctionnalités

- Recherche d'activités par catégorie, participants, contexte, durée et objectif.
- Générateur d'activités Six Bricks avec variations.
- Générateur d'histoires faciles ou plus difficiles, avec couleurs citées ou implicites.
- Favoris pour garder des idées de séance.
- Interface en français, avec traduction possible en anglais et chinois.

## Utilisation locale

Ouvrir simplement `index.html` dans un navigateur.
